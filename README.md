# IT2F_LIM_MIDTERM — Rental Fleet Vehicle Registration & Status System

Console app (Java 17, Maven, SQLite) with a layered DAO design.

## Run
- IntelliJ: open the folder as a Maven project, run `com.lim.fleet.Main`.
- Terminal: `mvn compile exec:java -Dexec.mainClass=com.lim.fleet.Main`

`scenario.db` is created automatically in the project root on first run.
